Local encryption, no application backend required.
Messages, files, and keys are processed in your browser using the Web Crypto API. This application does not intentionally transmit message contents, file contents, or cryptographic keys to a server. Your security also depends on the integrity of the application code, your browser, and your device. A compromised computer, malicious browser extension, memory-reading malware, someone using an unlocked device, or altered code delivered by a compromised hosting environment may expose sensitive data. Store access keys and private-key backups securely. Password-based encryption cannot protect weak passphrases. Token size and format remain visible. File encryption supports files up to 1 GiB using authenticated chunks; large-file saving uses browser capabilities and may require substantial memory if streamed saving is unavailable. Original filenames and types are not stored. Non-extractable RSA private keys are memory-only and cannot be recovered if lost; exportable keys need a secure user-managed backup. This app never saves private keys to localStorage. The RSA public key is public and remains in the workspace after an inactivity lock; private keys, access keys, messages, and results are cleared. The privacy lock has no password and is not an authentication boundary. ChaCha20-Poly1305 is not offered because browsers do not provide it through native Web Crypto; this app avoids unreviewed custom cryptography.
