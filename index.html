Encrypt a file

Files always use AES-256-GCM, regardless of the selected text cipher.

Maximum 1 GiB. Files use chunked AES-256-GCM and the access key above. New encryption requires exactly the selected access-key length; decryption is not restricted by that setting. New encrypted files use the binary HWF2 format; earlier HWF1 files up to 1 MiB remain decryptable. Original filenames and types are not stored. Large files use a Save File picker where supported; other browsers may need substantial memory to prepare the download.
